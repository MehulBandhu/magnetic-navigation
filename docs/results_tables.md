The fit uses the last two thirds of each run. The envelope column is the parameter count of the best run at each compute level regressed on compute; it is the same in every condition because C depends only on size and steps and the largest model reaching a compute level is always the best, so it reflects the grid's schedule, not the task. For both: points along one cosine schedule are not independent runs of that length; the long run at step 8000 (0.876) beat the run whose schedule ended at 8000 (1.104), a 21% effect.
